BATTLEBOMB — HOW TO RUN IT (an online test build)
=================================================

This is a test build of BattleBomb for playing online together over Steam.
One of you hosts (Michael); the other joins (you).


BEFORE YOU START (both of you)
------------------------------
1. Install Steam and log in. Steam must be running before you start the game.
2. Be Steam friends with each other.
3. Unzip the folder anywhere (for example, your Desktop). Keep every file
   together. In particular, "steam_appid.txt" must stay next to
   "BattleBomb.exe", or Steam will not see the game.
4. Double-click BattleBomb.exe.
   - If Windows says "Windows protected your PC": click "More info",
     then "Run anyway". The build isn't signed yet; that's all it means.
   - If Windows asks whether BattleBomb may use the network, allow it.
5. Steam will say you are "playing Spacewar". That is Valve's test app,
   which this build borrows until BattleBomb has its own. It's expected.


CONTROLS
--------
Keyboard: WASD move, Space jump, J attack, K heavy (hold to charge),
L magic, I equipment, Esc settings / back.
Controller: left stick move, A jump, X attack, Y heavy, B magic,
RB equipment, Start settings.


HOSTING (Michael)
-----------------
Start a solo game as usual: pick your hero, then the chapter. A solo game
is open to your Steam friends automatically.

In the bottom-right corner there is a small "Net" panel. Its Steam line
shows your name and a long number: your Steam ID. Read it out to your
friend if they need it (see "If Join Game doesn't appear" below).


JOINING (the collaborator)
--------------------------
1. Start the game and stay at the title screen.
2. Open Steam's friends list (the Steam window, "Friends & Chat").
3. Find Michael. Click the small arrow next to his name and choose
   "Join Game".
4. Your game shows a lobby: pick your hero (A/D keys or the stick), then
   ready (Space or A).
5. You appear in Michael's world at the next checkpoint room he reaches.
   Until then, you'll see "Waiting for the host to reach a checkpoint room".

If "Join Game" doesn't appear:
- In your game's Net panel (bottom-right), type Michael's Steam ID (the
  long number from his Net panel) into the box, and press "Join".

If Michael sends you an invite in Steam chat instead:
- Start the game FIRST, then accept the invite. (If the game isn't
  running, Steam would try to start Spacewar instead.)


LEAVING
-------
Guest: Esc, then "Leave the game". You can join again the same way.
Host: leaving ends the game for both of you. Your friend's progress is kept
up to the last checkpoint room they reached.


IF SOMETHING GOES WRONG
-----------------------
Tell Michael what you saw, and on which PC. A photo of the screen helps.
If the game shows "Connection problem..." for more than a few seconds,
it will give up after ten seconds and say so. That's expected on a bad
connection; please mention it.
